# rag-eval-abstention

**让 RAG 学会说"我不知道"：拒答阈值如何用覆盖率换精确率。**

一个**零依赖（只用 numpy）**的 RAG 评测骨架，把三件事的关系量化出来：
**检索质量 → 拒答阈值 → 回答精确率 / 幻觉率**。

> 核心结论：不拒答时回答精确率 **0.633**、幻觉率 **0.367**;
> 在置信度阈值 τ=0.30 处拒答 18% 的查询后，精确率升到 **0.755**、幻觉率降到 **0.200**。
> **放弃一部分覆盖率，买回的是"敢不敢信"的那部分确定性。**

---

## 一、为什么要自己搭骨架

真实系统里，"检索不好"和"模型乱编"这两件事会混在一起，出了问题往往归因不清。
本仓库把流水线**拆成可替换的零件**，让每个环节的贡献单独可测：

```
合成语料 → BM25 检索 → 词面重排(逻辑回归) → [模拟回答器] → 拒答策略 → 指标
                                        ↑
                              换成真实 LLM 时只替换这一个函数
```

**必须说清楚的一点**：这里的"回答器"是**行为可控的模拟器**，不是 LLM。
它的行为假设写在 `src/pipeline.py` 的 `answer_sim` 里，只有三条：

| 情况 | 答对概率 |
|---|---|
| 金标文档排在 top1 | 0.90 |
| 金标在 top-k 内但不在 top1 | 0.55 |
| 金标完全没被召回 | 0.20(即 80% 概率给出无依据的答案 → 记为幻觉) |

这样做的目的是：**把"会不会编"从模型能力里剥离出来，只留下"证据在不在、排第几"这个变量**。
换成真 LLM 时，`answer_sim` 换成一次 API 调用即可，其余代码与指标不变。

## 二、数据

- 60 篇文档，10 个主题，每主题 5 句模板句；
- 120 条查询，每条 1–3 个金标文档；
- **刻意制造的难点**：查询措辞与文档用词**不完全一致**(约 60% 的查询把主题词替换成同义词),
  迫使检索依赖 2-gram 匹配而不是精确关键词。

## 三、检索质量（测试集 60 条查询）

| 方法 | Recall@5 | 金标覆盖率@5 | MRR |
|---|---|---|---|
| BM25 | 0.867 | 0.761 | **0.576** |
| BM25 + 重排 | **0.883** | **0.800** | 0.546 |

重排提升了召回与覆盖率，但**MRR 略降**(0.576 → 0.546)——它把一些正确答案挤到了第二、三位。
这也是真实系统的常见现象：**换指标就换结论**，所以下面所有结论都以"回答质量"为准，而不是以 MRR 为准。

## 四、拒答阈值扫描（核心结果）

| 阈值 τ | 覆盖率 | 回答精确率 | 幻觉率 | 选择性风险 |
|---|---|---|---|---|
| 0.05(几乎不拒答) | 1.000 | 0.633 | 0.367 | 0.367 |
| 0.20 | 0.917 | 0.691 | 0.283 | 0.309 |
| **0.30** | **0.817** | **0.755** | **0.200** | **0.245** |
| 0.40 | 0.667 | 0.550 | 0.300 | 0.450 |
| 0.55 以上 | 0.000 | — | 0.000 | — |

风险—覆盖率曲线下面积 **AURC = 0.385**。

**三点观察：**

1. **拒答确实买到了精确率**:τ=0.30 时放弃 18% 的查询，精确率 +12 个百分点，幻觉率几乎减半；
2. **曲线并不单调**(τ=0.40 时精确率反而掉到 0.550)——说明当前的重排置信度**不是充分校准的信号**。
   这是诚实的结果，不是可以掩盖的噪声：能当"不确定性度量"用的分数，必须单独验证它的校准质量；
3. **τ>0.55 之后模型什么都不答了**——阈值定得太高，系统就退化成"拒答机器"。**拒答本身要付代价**,
   所以正确的做法是画出这条曲线，由业务决定工作点，而不是拍一个阈值。

## 五、复现

```bash
pip install -r requirements.txt          # 只需要 numpy
python src/run_experiment.py             # 约 5 秒
python src/run_experiment.py --queries 400 --k 8
```

输出：`results/metrics.csv`(每个阈值一行的覆盖率 / 精确率 / 幻觉率 / 选择性风险)。

## 六、局限（明确写出）

- **回答器是模拟器**：结论说明的是"检索 + 拒答"这条链路，不能直接外推到某个具体 LLM;
- **BM25 + 词面重排**：没有向量检索、没有真正的 cross-encoder，重排器的特征只有 5 维；
- **语料是模板生成的**：难点（同义改写、主题内干扰）是设计出来的，不是真实分布的采样；
- **样本量小**：测试集只有 60 条查询，τ=0.40 处的非单调很可能是小样本波动，没有报告置信区间；
- **AURC 只在当前阈值网格上算**，不是连续积分。
